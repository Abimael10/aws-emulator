ListAWSDefaultServiceQuotas

## Description
This issue bundles 8 net-new causes, one per ServiceCode. Model basis for all 8 causes: Smithy ListAWSDefaultServiceQuotas(ServiceCode required, @pattern ^[a-zA-Z][a-zA-Z0-9-]{1,63}$) -> output Quotas: ServiceQuotaListDefinition of ServiceQuota{ServiceCode, ServiceName, QuotaArn, QuotaCode, QuotaName, Value (double, range 0..10000000000), Unit, Adjustable, GlobalQuota, UsageMetric: MetricInfo, Period: QuotaPeriod, Description (@length 0..350)}. The model fixes the SHAPE of a row but says nothing about which values belong to which QuotaCode, so the AWS side of each cause below is 'recorded behavior only' — it is the recorded AWS ListAWSDefaultServiceQuotas response for that ServiceCode. The requirement is the per-QuotaCode binding and AWS's own Description/QuotaName text, never the one recorded number as such.
