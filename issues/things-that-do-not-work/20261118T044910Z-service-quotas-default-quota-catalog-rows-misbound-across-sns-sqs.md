## Operation
ListAWSDefaultServiceQuotas

## Description
TEN causes, one per ServiceCode, bundled because they share one fault: for these ServiceCodes the emulator's default-quota catalog publishes a row under a QuotaCode that does not belong to that code. The row served under a code carries another quota's QuotaName, Value, Unit, Adjustable, Period, UsageMetric or QuotaContext, or a Description the emulator worded itself rather than the one the service publishes; and some recorded QuotaCodes are published under no row at all. The HTTP status is correct (200) in every cause — the defect is entirely in the per-code CONTENT of $.Quotas.

SHARED AWS REFERENCE. Smithy (com.amazonaws.servicequotas#ServiceQuotasV20190624): ListAWSDefaultServiceQuotas takes ServiceCode (required, @length 1..63, @pattern ^[a-zA-Z][a-zA-Z0-9-]{1,63}$) and returns Quotas: ServiceQuotaListDefinition, paginated by NextToken/MaxResults; errors AccessDeniedException 403, IllegalArgumentException 400, InvalidPaginationTokenException 400, NoSuchResourceException 404, ServiceException 500, TooManyRequestsException 429. ServiceQuota members: QuotaCode @length 1..128, QuotaName, Value (double, @range 0..10000000000), Unit, Adjustable (boolean, default false), GlobalQuota (boolean, default false), UsageMetric: MetricInfo (MetricNamespace, MetricName, MetricDimensions map @length 0..10, MetricStatisticRecommendation @pattern ^(Sum|Maximum)$), Period: QuotaPeriod (PeriodValue, PeriodUnit enum), QuotaContext: QuotaContextInfo, Description @length 0..350. The model fixes the row SHAPE only; WHICH quota is published under WHICH QuotaCode, and the exact AWS wording of each Description, is recorded behavior only — the recorded ListAWSDefaultServiceQuotas response for each ServiceCode is the reference. The rule AWS follows: the row returned under a QuotaCode describes the quota the service publishes under that code, with that service's own wording (never a paraphrase, never a neighbouring quota's text), and a quota whose code is not published is returned under no code at all.

SHARED FIX LOCATION. The service-quotas default-quota catalog data for these ServiceCodes and the handler that assembles ServiceQuota rows from it (the per-ServiceCode catalog tables consulted by the ListAWSDefaultServiceQuotas handler in services/service-com-amazonaws-servicequotas-servicequotasv20190624), not the serializer: the shape and status are already right.
