# artifact ListReports omits most published report catalog entries and drops the date-time millisecond component

> _Note: this issue was identified against the code base at commit `9c31bf6152f020b6d0683107981107b2a4f16ac3`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Description
One net-new wire divergence on the artifact service: ListReports answers 200 but the body it serves is not the published report catalog AWS returns, and the TimestampAttribute members it does serve are rendered without their fractional-second group. 1 cause.

=== Cause 1 of 1: ListReports returns a reports list that is a small subset of the published catalog, and serializes periodStart/periodEnd without milliseconds (fixture artifact-catalog-list-reports, step task#1) ===

AWS: Smithy (services/service-com-amazonaws-artifact-artifact/smithy-model/com-amazonaws-artifact-artifact.json): ListReports is GET /v1/report/list with httpResponseCode 200, @readonly, input { maxResults (httpQuery, @range 1..300), nextToken (httpQuery, @length 1..2048) }, output { reports: ReportsList, nextToken: NextTokenAttribute @length 1..2048 }, and @paginated(inputToken: nextToken, outputToken: nextToken, pageSize: maxResults, items: "reports"); modeled errors AccessDeniedException 403, ValidationException 400, ResourceNotFoundException 404, ServiceQuotaExceededException 402, ThrottlingException 429, InternalServerException 500. ReportsList is a list of ReportSummary whose members are id -> ReportId (@pattern ^report-[a-zA-Z0-9]{16}$), arn -> LongStringAttribute (@length 1..2048, @pattern ^[^<>]*$), version -> VersionAttribute (long, @range min 1), name/series/category/companyName/productName -> ShortStringAttribute (@length 1..256), description -> LongStringAttribute (@length 1..2048), state -> PublishedState, uploadState -> UploadState, acceptanceType -> AcceptanceType, statusMessage, and periodStart/periodEnd -> TimestampAttribute with @timestampFormat date-time. Why: a client relying on AWS's behavior cannot enumerate the compliance catalog. Compliance automation and report pickers that page ListReports to the end and then call GetReport by id never see most published reports, so an auditor looking for the EBA/Bank-of-Italy Circular-285 user guide or a SageMaker Neo VPAT finds nothing to request or download, and inventory/diff jobs conclude those documents were withdrawn.
