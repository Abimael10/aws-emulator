ListAWSDefaultServiceQuotas

## Description
Shared fault: the ServiceCode-keyed default-quota catalog behind ListAWSDefaultServiceQuotas is not AWS's published default-quota catalog. For three ServiceCodes the emulator answers HTTP 200 (same status as the recording, so the divergence is purely the body) with rows that (a) carry no Description at all, (b) carry ANOTHER quota's QuotaName / Value / Unit / Adjustable / Period / UsageMetric under a published QuotaCode, or (c) are absent from the Quotas list entirely. 3 causes are bundled here; ALL THREE must be closed.

General AWS grounding (applies to every cause). Smithy (services/service-com-amazonaws-servicequotas-servicequotasv20190624): ListAWSDefaultServiceQuotas(ServiceCode required, length 1..63, pattern ^[a-zA-Z][a-zA-Z0-9-]{1,63}$; NextToken; MaxResults 1..100) -> ListAWSDefaultServiceQuotasResponse{Quotas: ServiceQuotaListDefinition, NextToken}; ServiceQuota members ServiceCode, ServiceName, QuotaArn, QuotaCode (1..128), QuotaName, Value (QuotaValue, double, range 0..10000000000), Unit, Adjustable (boolean, default false), GlobalQuota (default false), UsageMetric (MetricInfo), Period (QuotaPeriod), QuotaContext, Description (QuotaDescription, length 0..350); errors AccessDeniedException 403, IllegalArgumentException 400, InvalidPaginationTokenException 400, NoSuchResourceException 404, TooManyRequestsException 429, ServiceException 500.
