## Operation
ListAWSDefaultServiceQuotas

## Description
SHARED FAULT: the emulator's seeded default-quota catalog behind ListAWSDefaultServiceQuotas is incomplete. For the ServiceCode values below the operation answers HTTP 200 with a `Quotas` list that omits quota rows AWS publishes, and where a row IS published it can omit `Description` or carry the wrong `Adjustable` flag. This issue bundles TEN separate per-ServiceCode causes; every one must be closed before submitting.

Smithy citation used throughout: ListAWSDefaultServiceQuotas(ServiceCode required, @length 1..63, @pattern ^[a-zA-Z][a-zA-Z0-9-]{1,63}$) -> ListAWSDefaultServiceQuotasResponse{NextToken, Quotas: ServiceQuotaListDefinition}, errors AccessDeniedException(403) / IllegalArgumentException(400) / InvalidPaginationTokenException(400) / NoSuchResourceException(404) / ServiceException(500) / TooManyRequestsException(429); paginated(items=Quotas, pageSize=MaxResults 1..100). ServiceQuota members: ServiceCode, ServiceName, QuotaArn, QuotaCode (@length 1..128), QuotaName, Value (QuotaValue double, range 0..1e10), Unit, Adjustable (boolean, default false, "Indicates whether the quota value can be increased"), GlobalQuota (boolean, default false), UsageMetric (MetricInfo), Period (QuotaPeriod), Description (@length 0..350). The model defines the SHAPE of a row but not the catalog CONTENT, so the row inventory per ServiceCode is "recorded behavior only" and is taken from the recorded 200 responses.

GENERAL REQUIREMENT (applies to all ten causes): for a given ServiceCode the emulator must publish the same SET of QuotaCode rows AWS publishes for that code, each row fully populated — ServiceCode and ServiceName as AWS names them, QuotaArn in the AWS form arn:aws:servicequotas:<region>::<ServiceCode>/<QuotaCode>, QuotaName, Value, Unit, Adjustable, GlobalQuota, and Description when AWS publishes one, plus Period/UsageMetric where AWS attaches them. The region, account field and row ORDER are environment-dependent and are not the requirement; the row set and each row's field values are.
