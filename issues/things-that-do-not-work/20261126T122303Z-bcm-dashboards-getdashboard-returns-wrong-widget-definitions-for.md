# bcm-dashboards GetDashboard returns wrong widget definitions for AWS-managed dashboard catalog entries

> _Note: this issue was identified against the code base at commit `48c578157d340acc1801129cac664ba18287deab`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Operation
GetDashboard

## Description
GetDashboard on the AWS-managed (curated) dashboards that AWS Billing and Cost Management ships pre-created in every account answers 200 with the right envelope (arn/name/type/createdAt/updatedAt and a WidgetList), but the WIDGET CONTENT of the emulator's built-in catalog is a different dashboard definition from the one AWS serves. The divergence is systematic, not a single bad field: per widget id the emulator substitutes a different title, a different description, a different width, a different displayConfig union member (graph vs table), and a different queryParameters union member / groupBy dimension / metric / granularity / timeRange. Whole widget ids are also present in one side only, so the curated layouts do not line up at all.

This is ONE fault - the seeded AWS-managed dashboard catalog is wrong - with FIVE causes, one per curated dashboard the corpus reads back. Each cause must be closed before this issue is submitted.

Cause 1 of 5 - the cost-overview curated dashboard (fixture bcm-dashboards-catalog-get-dashboard, step task#1).
AWS: recorded behavior only. The Smithy model (GetDashboard -> GetDashboardResponse.widgets: WidgetList @length min 0 max 20, each Widget carrying title/description/width/configs, configs[].displayConfig a union of graph|table and configs[].queryParameters a union of costAndUsage|reservationCoverage|reservationUtilization|savingsPlansCoverage|savingsPlansUtilization) constrains the SHAPE only; it says nothing about which curated widgets an AWS_MANAGED dashboard contains. The recording is therefore the requirement: for a given curated dashboard ARN, AWS returns a fixed set of widget ids, and for each id a fixed title, description, width, displayConfig member and queryParameters member. In this dashboard the recording has, among others, widget 2a7e51a22e1c00af3843c5cccb82b046 titled 'Cost By Top Spending Services'; widget a15901be3f2d2c9f07f2c90938ca73d3 titled 'Overall Cost Efficiency' described 'Monthly cost efficiency score trend across your usage.'; widget a80cc87050b1e60b97c65e38be2876ae titled 'Cost By Service Breakdown' described 'Tabular breakdown of monthly unblended costs by service.' grouping by DIMENSION/SERVICE; and widget ce2a10fcd1ab3961dc32b6a3c595166c with displayConfig.graph.UnblendedCost.visualType STACK, metrics[0] UnblendedCost, groupBy[0] DIMENSION/LINKED_ACCOUNT and NO costAndUsage.filter.
