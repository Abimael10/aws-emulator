## Description
SHARED FAULT: the emulator's seeded default-quota catalog for ListAWSDefaultServiceQuotas is wrong per service code. For each `ServiceCode` below the emulator answers HTTP 200 with a `Quotas` list whose entries are bound to the WRONG QuotaCode (a row's QuotaName/Description/Value/Unit belong to a different quota than the QuotaCode it is published under), carry re-worded Description/QuotaName text, misflag `Adjustable`, or omit `Period`/`UsageMetric` altogether. The quota catalog is reference data a client reads to discover a service's AWS default limits, so each code must resolve to that quota's own name, description, value and unit.

AWS (applies to every cause): Smithy ListAWSDefaultServiceQuotas -> ListAWSDefaultServiceQuotasResponse.Quotas: list<ServiceQuota>; ServiceQuota members ServiceCode (@length 1-63, @pattern ^[a-zA-Z][a-zA-Z0-9-]{1,63}$), QuotaCode (@length 1-128), QuotaName, Value (QuotaValue double @range 0-10000000000), Unit, Adjustable (boolean, default false, "Indicates whether the quota value can be increased"), GlobalQuota, UsageMetric (MetricInfo), Period (QuotaPeriod), Description (@length 0-350). The model fixes the shape but not the catalog contents, so the per-code rows are recorded behavior only: AWS returns, for one QuotaCode, exactly that quota's QuotaName, Description, Value and Unit. Both expected and actual status are 200 and no error is modelled for these requests (errors on this op are AccessDeniedException 403, IllegalArgumentException 400, InvalidPaginationTokenException 400, NoSuchResourceException 404, ServiceException 500, TooManyRequestsException 429) — the divergence is entirely in the response body, so there is no status/error-code/message requirement to quote here.

Fix: the service-quotas default-quota catalog data the ListAWSDefaultServiceQuotas handler serves — the per-ServiceCode seed table and its QuotaCode-to-row binding — not the operation's serializer: the response shape is correct and the status is 200. Each code must key the quota it names, and rate quotas must carry Period and UsageMetric.
