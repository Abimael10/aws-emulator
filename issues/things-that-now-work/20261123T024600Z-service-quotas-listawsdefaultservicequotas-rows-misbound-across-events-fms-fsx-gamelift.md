SIX causes, one per ServiceCode, all of the same fault: the emulator's default-quota catalog publishes a row under a QuotaCode whose QuotaName/Value/Unit/Period/UsageMetric/Description belong to a DIFFERENT quota of the same service, re-words the Description in the emulator's own prose, or omits a published code's row altogether. THE SHARED RULE. ListAWSDefaultServiceQuotas returns, for the requested ServiceCode, one ServiceQuota row per quota AWS publishes for that service, and the row published under a QuotaCode carries the QuotaName, Value, Unit, Adjustable, GlobalQuota, Period, UsageMetric, QuotaContext and Description of the quota AWS publishes UNDER THAT CODE, with the Description worded as the service words it (not a paraphrase, not a neighbouring quota's).
